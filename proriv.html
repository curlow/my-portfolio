ПРОРЫВ

Сайт для типографии в Тихвине

О проекте

Сайт для типографии «ПРОРЫВ» в Тихвине. Полный цикл: дизайн + разработка. Каталог услуг, онлайн-заявка, карты водителя для тахографов, интеграция с Яндекс Картами.

Что реализовано

  • Адаптивный дизайн для всех устройств
  • Каталог услуг с каруселью
  • Раздел «Карты водителя» с описанием двух типов
  • Форма обратной связи и онлайн-заявка
  • Интеграция Яндекс Карт с меткой офиса
  • Шапка с быстрыми действиями (печать, звонок)

Технологии

HTML CSS JavaScript Яндекс Карты
